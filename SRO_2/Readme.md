О ПроектеВеб-приложение «АТУ Events» — это современный одностраничный сервис (Single Page Application / SPA), разработанный для автоматизации процесса анонсирования, фильтрации и записи студентов на университетские мероприятия.Проект выполнен в рамках СРО №16 по дисциплине «Языки и технология программирования» и демонстрирует практическое применение ключевых тем курса (Лекции 1–8).💡 Идея проекта: Упростить доступ студентов АТУ к академической, спортивной и культурной жизни университета через единый, удобный и красивый веб-интерфейс.🚀 2. Функциональные Возможности👨‍🎓 Для Студентов🔍 Умный поиск: Мгновенный поиск по названию события, спикерам и локациям.🏷️ Категоризация: Фильтрация по направлениям (IT & Наука, Спорт, Культура, Карьера, Хакатоны).📝 Онлайн-запись: Форма регистрации на мероприятие с автоматической валидацией данных.⏳ Счетчик мест: Динамический пересчет оставшихся мест в реальном времени.🏛️ Для Организаторов➕ Панель добавления: Создание новых событий с указанием даты, времени, лимита участников и тегов.📊 Мониторинг: Просмотр списка зарегистрированных участников по каждому событию.🧠 3.
