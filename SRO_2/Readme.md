# Каталог мероприятий университета (Mini-Project #16)

## 1. Название и цель проекта, проблема и целевая аудитория
Проект представляет собой цифровую информационную систему для централизации студенческих мероприятий, автоматизации поиска, фильтрации и онлайн-регистрации с защитой от переполнения аудиторий.

## 2. Анализ предметной области и аналогов
В сравнении с универсальными платформами (Timepad) и соцсетями (VK), данное решение ориентировано строго на университетскую среду, имеет малый вес, персистентное JSON-хранение и исключает коммерческий шум. Источники: внутренняя документация ВУЗа, анализ платформ Timepad и VK События.

## 3. Функциональные возможности и ограничения
* Публикация и администрирование мероприятий.
* Фильтрация каталога по категориям и поисковым запросам.
* Регистрация и отмена участия студентов с жестким контролем квот (`max_seats`).
* Ограничение: локальное хранение данных в формате JSON (без использования внешних СУБД).

## 4. Стек технологий, архитектура и структура файлов
* Язык: Python 3.10+
* Хранение данных: JSON
* Тестирование: Встроенный модуль `unittest`
* Структура: `/src/main.py`, `/tests/test_events.py`.

## 5. Инструкция по установке и запуску
1. Клонируйте репозиторий: `git clone https://github.com/username/university-event-catalog.git`
2. Перейдите в папку проекта: `cd university-event-catalog`
3. Запустите тесты: `python -m unittest discover -s tests`
4. Запустите приложение: `python src/main.py`

## 6. Примеры использования и скриншоты
Приложение управляется через консольные вызовы классов и сохраняет состояние в файл `events.json`. Скриншоты интерфейса доступны в папке `/screenshots/`.
