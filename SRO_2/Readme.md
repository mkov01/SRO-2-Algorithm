🎓 Университетский Каталог Мероприятий (АТУ)Дисциплина: Языки и технология программированияТема СРО: №16 — Интерактивный каталог мероприятий университета (Лекции 1–8)Учебное заведение: Алматинский Технологический Университет (АТУ)Стек: HTML5, Tailwind CSS, JavaScript (ES6+ Native)📌 1. Описание ПроектаВеб-приложение «АТУ Events» — это интерактивный одностраничный сервис (SPA) для публикации, поиска и записи студентов на академические, спортивные, культурные и карьеры мероприятия Алматинского Технологического Университета.Проект разработан в рамках выполнения СРО №16 и демонстрирует практическое применение фундаментальных концепций программирования (Лекции 1–8).🎯 2. Основные Функциональные Возможности (FR)FR-01 (Каталог и события): Динамический рендеринг карточек мероприятий с информацией о датах, местах и доступных местах.FR-02 (Запись участников): Форма регистрации студентов с валидацией имени, группы и Email.FR-03 (Фильтрация и поиск): Мгновенная фильтрация по категориям (IT & Наука, Спорт, Культура, Карьера и др.) и текстовый поиск.FR-04 (Панель организатора): Добавление новых мероприятий с автообновлением счетчиков.FR-05 (Мониторинг мест): Автоматический пересчет свободных мест и блокировка записи при исчерпании лимита.FR-06 (Интерактивная презентация): Встроенный слайдер на 10 слайдов для защиты СРО.🧠 3. Связь с Учебным Материалом (Лекции №1–8)Лекции 1–3 (Введение и структуры): Модульная архитектура приложения, обработка DOM-событий (click, input, submit).Лекция 4 (Циклы): Использование циклов и методов перебора (forEach, map) для генерации интерфейса карточек и списков.Лекция 5–6 (Функции и Массивы): Декомпозиция логики на функции (renderEvents, handleRegistration), работа с методами массивов (filter, sort, reduce, some, unshift).Лекция 7–8 (Строки, Regex и Объекты): Валидация Email с помощью регулярных выражений (RegEx), использование строк (toLowerCase, trim) и структур данных JSON (объекты Event и Participant).📁 4.
